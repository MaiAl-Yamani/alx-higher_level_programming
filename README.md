# ALX Higher-Level Programming

Python, SQL, and introductory JavaScript exercises completed as part of the **ALX Software Engineering Programme**.

This repository documents my progression through programming fundamentals, object-oriented design, testing, data handling, and introductory database and web programming concepts.

## Topics covered

| Area | Topics |
| --- | --- |
| Python fundamentals | Control flow, functions, imports, modules, data structures, exceptions |
| Object-oriented programming | Classes, objects, inheritance, and Python's object model |
| Testing | Test-driven development exercises |
| Data and persistence | File I/O and SQL fundamentals |
| JavaScript | Introductory JavaScript programming |
